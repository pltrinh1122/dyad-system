## Proposed tunings (each H; a tuning is a craft-zone PR on the Operator's prompt)
- **The target axis is a knob.** This run moved targets from segments to ways of working mid-phase 2. A knob `axis`
  (`segment` · a named target axis), set before phase 2, would have asked it first (phase 2, entries 28–30).
- **Plainness gains `vague`.** Phase 1's O7 amendment ("asked operator for what?", entry 17) was a statement too vague
  to observe, an outcome the plainness record does not name.
- **Phase 1 checks orthogonality before it asks.** The falsification the Operator asked for (entry 21) found overlaps
  that a standing attack in the step would have found first.
- **Symptoms are drawn from the canon.** Phase 3's views should list each target's symptoms from the canon (#699), so
  "are they canonical?" (entry 37) is answered by the record, not by a falsification at review time.
- **A plan revision during a phase is an execution risk.** Fifteen plan revisions were asked in this run; a phase's
  answer that changes the plan should be asked as one revision at the phase's end (`batch` within a phase).
