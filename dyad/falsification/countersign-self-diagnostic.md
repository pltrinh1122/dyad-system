## C1–C6: the model — two kinds of check

| # | Attack | Result | Survivor |
|---|--------|--------|----------|
| C1 | **"Coded rules" names the first kind.** | **Refuted as a name** | In a dyad corpus a Rule is prose (dyad-system Rule-4: an Agent Rule is a file in `dyad/rules/`), so "coded rule" would collide with every Rule. The kind is a **coded check**: a test, a guard or an invariant (the play-book §1). |
| C2 | **A prose claim is checked by reading it.** | **Refuted as stated, survives scoped** | A reading has no failure condition of its own: one that finds nothing has checked nothing. A prose claim is a check only when read **against a written attack** — what would have to be found for it to be false; a claim with no attack is not a check. |
| C3 | **The kinds divide what is checked: code by coded checks, prose by prose claims.** | **Refuted** | dyad-system's `rules.py` (a Rule's block counts), `vocabulary.py` and `references.py` are coded checks of prose; a unit's contract coverage is a prose claim about code. The kind is *how* a thing is checked, never *what*. |
| C4 | **One kind suffices.** | **Refuted, both ways** | Coded alone: coherence has no coded check ("No script can decide coherence or orthogonality", dyad-system Rule-5) and neither has contract coverage. Prose alone: unrepeatable, and paid in inference on every run — dyad-system #143's first concern. Both are required, as the Operator said. |
| C5 | **A prose claim stays prose.** | **Refuted** | A claim whose attack fails on successive runs, by a reading that could be written down, is an inference task met again, and recurrence proposes code (dyad-system Rule-13 property 1); in this craft's terms it is the shape of the codify edge. The record carries a `codify?` column (§7). |
| C6 | **The two kinds and the prompt's four levels are separate schemes.** | **Refuted** | The four levels are the two kinds at two scopes — unit-test code is unit × coded, integration-test code system × coded, unit-invariant inference unit × prose, system-invariant inference system × prose — and the prompt's order is coded before prose, unit before system within each (§2). |
