# sysarch craft vocabulary (Tended terms)

One row per term. Craft terms are referenced, never defined, by the Agent vocabulary
(`dyad/vocabulary/VOCABULARY.md`, Rule-6 Boundaries); a core kernel may say `projector` or
`resolver` and means the sense here. `rule` names the craft rule (`../rules/`) that owns the term.
Rows moved from the Agent vocabulary by d-work #160 (plan attack 14: `manifest` stays core, its
kernel uses it; `guard` and `corpus` stay core, re-owned by Rule-11). Checked by the craft guard
(`dyad craft check sysarch`: well-formed, namespaced, every `rule` exists).

| term | definition | rule |
|------|------------|------|
| projection | a mechanical rendering of parsed corpus data onto a surface; generated by a projector, never hand-drawn, never committed | projection |
| projector | the craft code (`crafts/<craft>/projectors/project_<surface>.py`) that produces one projection, with its mechanical check; discovered by the core runner | projection |
| surface | a viewing form the Operator reads: ERD, system schema, entity cards, events; each has one projector, in one craft | projection |
| library | every System Infrastructure dependency that is not kernel; replaceable, each naming its replacement | manifest |
| reference | a value in one entity instance's field that names another instance: a row id, a Rule number, a record path, a commit, a change-log key; resolved by exactly one resolver | references |
| resolver | the register entry (`references.REFERENCES`) and function that decide a reference's target instance exists; one per reference kind — the reference guard's own, another Rule's guard, or `world` (unresolvable, inference) | references |
| guard contract | what a guard declares: `ENTITY`, `CORPUS`, `FIELDS`, `TRANSACTION`, `check_package(root)` and, when TRANSACTION, `check_transaction(root, base, head)`; `describe(root, pkg)` for the entities surface; one definition, `dyadlib.CONTRACT`, by which the runner discovers modules and fails one that lacks it | guards |
