Released 2026-11-11 at db6e808c: the bundle `v1.3.0`, with `dyad-operator-v1.3.0`, `cabinet-v0.7.0`,
`chronicle-v0.4.0` and `sysadmin-v0.3.3`.

What changed:
- cabinet 0.7.0: the unit and session tidy, one play-book and one decision record for tidying the units and
  sessions of one account.
- dyad-operator 1.3.0:
  - precedents captured at every Done, and a record deciding which outcomes a precedent may settle;
  - incidents logged and hardened, with a fence so an audit never misses unlogged ones;
  - the Done question carries a releases clause, and a done head is always the full sha;
  - a bundled craft is judged on its own tree;
  - the closing line's Coming part is its own preference, and Awaiting you names the unit to answer in.
- chronicle 0.4.0: the roman à clef form, with its key beside it, and decision records for a product-marketing
  pitch and a lean canvas, plus a method for diverging before converging on root causes.
- sysadmin 0.3.3: the change-log actor record declares each outcome's precedent effect.

Upgrade: install the core from the release (`dyad install --from <release>`), then each craft you use
(`dyad craft install`), and run `dyad check`.
