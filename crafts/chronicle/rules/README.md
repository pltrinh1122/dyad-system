# Tended Rules of the chronicle craft

One file per rule, any form, no Rule-4 block, no sweep (Rule-4 Boundaries); each opens with the core Rule whose
kernel reads it, if any. The core keeps the process — what a row is, who disposes, what a provenance record holds
(Rules 2, 3, 7) — and this craft keeps the practice: how a piece is written for readers from that record without
inventing it. The craft is a core for every form plus one section per form; a form section narrows the core and never
loosens it. Terms: `../vocabulary/CRAFT.md`. Records: `../falsification/rules/`.
