# d-work traces

A d-work trace is the per-d-work performance record the Operator and the Agent use to assess
bottlenecks by the same measures (d-work #212). The format, the buckets and the procedure are the
play-book's: `dyad/playbooks/dwork-trace.md`, run by `dyad dwork trace <id> --out`. The traces
themselves live in the trace store, `agent-corpus/d-work/traces/<id>.md`, not here.
