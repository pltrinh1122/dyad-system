# Tunables at 1.0 — the table (d-work #590)

Report for #590's definition of done (*proposed*, plan `agent-corpus/d-work/plans/590.md`): every number 1.0 lets the
operator tune, its preference key, its allowed values, its default as a DMC states it, and what reads it; altitude
among them; and every other number in the code with the reason it is not yours.

Taken against `main` at 5704681f. **The DMCs are canonical** (`dyad:tunables`, `dyad/dmc/schema.md`); this file is
the dated reading of them, generated from the records for this report (plan #590 F4), and goes stale at the first
change to a threshold.

**Test (F1).** A *tunable* is a number whose change alters what reaches the operator, or when: a threshold, a
ceiling, a target. A number whose change alters only correctness or speed is an *engineering constant* (part 2).
