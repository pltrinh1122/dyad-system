# Pseudonym map (instance, agent zone) — d-work #166

Class B of the disclosure craft's redaction rule (`crafts/disclosure/rules/redaction.md`): the
proprietary substance of this practice is **pseudonymized, not deleted**, so that a report keeps its
counts, its groupings and its co-occurrences while disclosing nothing. This file is the map, and it is
the reason a report built today is comparable with one built next month.

**This file never leaves the system.** It is the inverse of every report the play-book produces: with
it, any reader recovers exactly what the report was built to hide. It is tracked so that a pseudonym is
stable across reports and across sessions, and it is instance state — never craft content (Rule-11
property 1), never copied into a projection, never attached to a delivery.

One row per mapped value. `real` is the value as it appears in the corpus; `pseudonym` is what a report
shows instead; `kind` is why it is Class B; `since` is the d-work that allocated it. A pseudonym, once
allocated, is never reassigned and never reused for a different real value — a reassignment silently
falsifies every report already delivered.
