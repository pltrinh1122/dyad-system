# External summaries (instance, agent zone) — d-work #166

One file per month, `<YYYY-MM>.md`: the Agent-authored external summary of each failure-mode group in
that month's incidents, written for the audience the report is built for (the `AUDIENCE` parameter of
`dyad/playbooks/ds-report-incidents.md`). Class C of the disclosure craft's redaction rule — retained,
and passed through both redaction gates exactly as everything else is, because prose written by
inference is precisely where an internal leaks.

Empty until a report is built. A summary is written in the d-work that builds the report, never by a
run-book command (the `summarize` step reports what is missing; it writes nothing).
