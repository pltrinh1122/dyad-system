# Plan #412 — attendance as a declared set with a default: the Operator's span is over attended seats

## Intent as read
The constraint is not the number of sessions but the number the Operator *attends*: a hundred sessions
are fine while only `program` is attended and orchestrates the rest. Requirement: (1) the program seat
tracks which seats, beyond program, the Operator attends; (2) by default only program is attended and
every other seat is unattended; (3) that default is a preference.
