**The procedure, as read (adding or refreshing a segment):**
1. **Derive** the segment's source tree, `<canvas set>/<segment>/why-tree.md`, independently, from its own anchor
   (revision 3). Its ids are local to the segment and append-only. It is judged on its own by `collateral-why-tree`.
2. **Project.** Each source node is looked up in the unified tree:
   - **known:** it maps to the unified node, which gains the segment's tag, or a join;
   - **new:** it gets the next free unified id.

   Every unified line names its sources, `⟵ <segment>:<id>, …`. So the unified tree is a function of the sources plus
   that mapping. A unified node with no source, or a source node with no unified line, fails.
3. **Judge** the unified tree. Its header carries, beside its own digest and each tag's, **each source tree's digest**,
   so a changed source makes the projection `stale` until it is projected again.
4. **Use.** A segment's canvas (`problem.md`) cites its **source** ids, its own derivation. Screening a new problem
   uses the **unified** tree. A red herring is found there and named by its sources.

**What this changes in what exists:**
- `platform-ops/why-tree.md` returns as the segment's source tree. Its content is #683's tree, ids unchanged, so its
  mapping is the identity and `problem.md`'s citations stay true.
- `why-tree.md` stays at the canvas-set level as the projection. Its lines gain `⟵` sources.
- `collateral-why-tree` gains two outcomes, **unsourced** (a unified node with no source) and **unprojected** (a source
  node with no unified line). `stale` also reads the source digests.

**Definition of done (proposed), superseding revision 3's.** Two PRs, in order (`order: required`):
1. **Craft zone:**
   - §6 rewritten for source trees and the projection, with the four steps above;
   - a tag added to a node edits only its tag list (revision 1's finding);
   - `collateral-why-tree` and `collateral-problem-depth` read per source and per projection;
   - `collateral-segment-rank.jsonld` (revision 2);
   - falsification rows.
2. **Infra zone:**
   - `platform-ops/why-tree.md` restored as source;
   - `regulated-engineering/` with every canvas section and its independent source tree (a fresh subagent, briefed
     without either tree);
   - `why-tree.md` projected from both, with every `⟵` mapping, and judged;
   - `index.md` with the ranking.
