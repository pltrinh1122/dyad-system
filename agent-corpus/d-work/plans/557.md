# Plan #557 — the orchestrating solo: a secretary chartered to run the d-work play-book for the home (falsified)

Base commit of main: 30a0eb33

## Intent as read
Row #557 was opened under #556's mandate (revision 2, attack L5): the d-work's **orchestration and execution** layer —
dispatching to units, collecting inbox reports, verifying heads and evidence, judging departures and incidents,
drafting the completion evidence and the Done question — belongs to a **solo**, not to the home, whose layer is
interaction only (`dyad/playbooks/d-work.md`, Layers, #556). The home keeps no desk (cabinet `naming.md` §2), so the
solo is a **secretary** with its own charter. A charter is a row of `preferences-corpus/MANDATES.md`, which only the
operator changes (Rule-2 Binding: a preference value is never accretable). This plan proposes that charter and the
craft data it needs; it decides neither.
