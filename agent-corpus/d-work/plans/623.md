**Ambiguous, with the reading taken:**
- **A1. "Upstream row".** Read: the row the fix would ride. That is either the row the fault blocks, or another open row
  whose files the fix shares, as #622 was for #620. A done row is never reopened (Rule-16), so the row that caused the
  fault is never a candidate.
- **A2. "Blocking".** Read: it stops a row's next act. An evidence block that is red, a gate refusal, or a merge that
  cannot run all count. A warning that blocks nothing is out: it is recorded, and work continues.
- **A3. "Downstream".** Read: surfaced in one row's verification, with its cause outside that row's own diff. A fault
  inside the row's own diff is the row's to fix, and nothing to decide.
- **A4. Who opens its own row.** Read: the criterion recommends; you dispose. A finding reaches a row only through your
  disposition (Rule-3 Scope). So the "own row" outcome is a proposal put to you, with the blocked row held meanwhile.

Duplicate: none. False premise: none.

**The threshold, proposed for the plan to falsify.** A blocking downstream fault gets its own row when any one of these
holds:
- (a) it blocks more than the one row, or `main` itself;
- (b) it is a second occurrence of the same failure mode;
- (c) no open row's definition of done covers its fix, so you would judge it on its own (`altitude` `split`);
- (d) its fix needs a zone or a unit the host row does not have.

Otherwise it rides: inside the blocked row, or in the open row whose files and definition of done cover it. Either way
the plan says so, and a revision is asked whenever `plan-departure` says `new-plan`. An existing fix is ported first,
before any of this.

**Applied to its own case:** #622 revision 2 meets (a), since `main` was red too, and (b), as F16's second occurrence. By
this threshold it would have been its own row. It is built and authorized, so the completion evidence applies the
record to it as a finding. It is not undone unless you say so.

**Counter.** A row of its own costs three questions and a hold on the blocked row, where a revision costs one question.
The criterion makes small fixes slower.
**Reconciliation.**
- Riding coupled #620's Done to #622's whole landing.
- The same timing test reached three rows in two days.
- The threshold sends a fault to its own row only when it spreads (a), returns (b), stands outside the host's purpose
  (c) or outside its zone (d). Every other fault still rides, at one question.
