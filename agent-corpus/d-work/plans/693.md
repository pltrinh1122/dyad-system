**Read: (b) is a pass of `collateral-segmentation`, and the comparison feeds its outcomes:**
- a problem class whose sufferers include a cell no segment holds → **unspanned** (a missed segment);
- two segments that suffer the same classes and share an anchor branch → **overlapping** (merge), and differing anchor
  branches keep them apart;
- a segment that (a) put on the map and (b) finds in no problem class → **off-class**, a new outcome: it is on the map
  for a problem the tree does not hold, so either its tree is owed or it is off the map;
- every segment and class agreeing in both directions → the map is **corroborated**, recorded in `index.md`.

**Product side, adjacent and read out:** "product-market fit" can also mean the product's features against the problem
classes (`solution.md` against the roots). The prompt names segments and problem classes only, so that check stays
for its own prompt, and the evidence reports it.
