## Survivor
Operate owns the alignment **check**: a run-book `<host>/runbooks/sessions.md` whose health command is
`dyad session audit` — for each live presence file a harness session whose title is the seat's `dyad session
name` form, and for each harness session titled in the seat form a live presence file; mismatches printed one
line each (`no harness session`, `no presence`, `title differs`, `stale while titled`), pass = none. Operate
runs it at every reply and on the program's request, records the event, and reports mismatches on its board;
remediation is the writer's (the seat touches; the program retitles/archives), never operate's write.
