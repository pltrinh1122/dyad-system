## Where a directive can live, and why this one goes in a Rule
Four containers exist. The memory cache is per-machine, is not corpus, does not travel with a
release at all, and failed within an hour of being written (#67). A play-book is for a recurring
*decision*, and this is not a decision — there is nothing to weigh. A README is read by a person,
never by the Agent as a binding. **An Agent Rule is the only container that ships with the core
craft and binds the Agent in the installing system**, which is exactly what "the Release includes
directives" asks for.

The owning Rule is **Rule-12**: it owns Rule-12's suite (`check_rule_12`) and its Enforcement
already names the runner and the test roots. Rule-14 property 3 owns *where the kernel-only path
runs*, not how the Agent types it; Rule-13 owns the move from inference to code, which #155 already
made.
