# Plan #568 — revise `dyad/dmc/promotion.jsonld` from its first use

Base commit of main: 141bcc8f

## Intent as read
The home's promotion question, the criterion's first live use (#566), was answered `Y`. That opened this row (P4,
adjacent to #566). The relay from home names five revisions, all taken from that use:
1. **S6 needs a single-owner anchor.** S6 counts only against an anchor with one owner. On #564, which has five
   owners, S6 fired for every candidate.
2. **P1 is ordered by dependency, then impact.** This comes before the smaller-plan tie-break. The presence gap
   preceded #130, #311 and #313, and #549 is cosmetic, yet the smaller-plan tie-break ranked #549 first.
3. **A candidate need not be a row.** Promises and findings can be named, and a `Y` opens a new row for each.
4. **An absorbed row is not valid.** A candidate absorbed by another row's plan is not valid. Example: #305, absorbed
   by #533 per plan #532's overlap table, row 6.
5. **Orphaned is not obsolete.** In the retirement reading, an orphaned child is not presumed dead.
