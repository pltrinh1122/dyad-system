## Plan
**Intent as read.** Revision 2's reading: this row advises the new system, writes its phase plan and bootstraps it; the
phases P1–P3 are that system's own rows.

**The advice (the craft play-book, Steps: another dyad system).** craft-instantiation-criteria: **D1 fires**
(users' conversations are sensitive; this system is public) and **D5 fires** (their retention and deletion are the
service's own). So `prompt-therapy` is a new dyad system on its own remote. Its code is 0BSD; its users' data lives
in the service's store, never in a repository.

**Mutation.**
1. **The phase plan**, `site/lean-canvas/prompt-therapy.md` in this system's canvas set (infra zone, one PR). It holds:
   - P0–P3 as revision 2 reads them, each with its definition of done for the new system's rows;
   - the partition table: what stays here and what lives there, by `dmc:intake-split`;
   - the two gaps found: no record places a row in a system, and Intake has no shape for an observation report;
   - the hand-up rule: consented, de-identified symptoms only.
   It carries no user data and no code.
2. **The bootstrap (P0)**, once the repository exists:
   1. **You create** the repository `prompt-therapy` (this session cannot create one) and attach it to this session.
   2. **`system-new`** (`dyad/runbooks/craft.md`): class `reversible`, role `operator`, its undo `rm -r <clone>/dyad`.
      It installs the core into a fresh clone, run through `dyad runbook run craft system-new`, which records its event.
      The run-book names the role as yours, because the remote's credential is: **you run it**, or you tell me to, and
      that answer is recorded as a departure from the role in the change log.
   3. **The new system's first ledger rows**, as `backlog`, each holding one phase's definition of done from the phase
      plan: P1, P2, P3. They are opened there on your prompt in that system, with their own plans and `Y`s.
3. **Change log**: one row in `workstation-corpus/CHANGELOG.md` for the `system-new` run (Rule-8, reversible), in a
   workstation-zone PR.
