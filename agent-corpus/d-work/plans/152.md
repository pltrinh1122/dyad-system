### 1. The Countersign Interaction Model (CIM)
**Five primitives, the same in every mode and every repo:**

| primitive | who → who | carries | asks? |
|---|---|---|---|
| **Initiation** | human → system (*prompt*), registered source → system (*signal*), or executor (*release trigger*) | the originating words or payload, kept verbatim | — |
| **Proposal** | agent → human | one path, its strongest counter, a reconciliation (Rule-10 = dsys "DFD turn") | exactly one question, the last line |
| **Countersignature** | human → system | answer ∈ {`yes`, `no`, `amend` + text}; basis ∈ {per-act, mandate, release}; the verbatim text; bound to a head or hash | — |
| **Report** | agent/executor → human | evidence (evidence block, event ids, counts) | nothing (a report never asks) |
| **Escalation** | system → human | what was unsigned or unhandled and why | becomes a Proposal, in explicit mode |

**Eight imperatives (I1–I8), binding in all three modes:**
- **I1: only a human countersigns.** Proposer ≠ disposer (Rule-2; dsys I-2).
- **I2: one question per reply, last line.** The answer grammar is `Y` / `N` / text. Text with `N`
  means *amend* (a linked re-entry), and text with `Y` is a Y plus a new prompt (Rule-3 Scope;
  dsys E3 `counter`).
- **I3: falsify before proposing** (Rule-9; dsys playbook gates).
- **I4: detect, don't dispose.** The standing license to challenge intent (frame).
- **I5: words kept verbatim.** Every prompt and countersignature is stored as given (Rule-7; dsys
  DecisionRecord).
- **I6: no self-initiation.** An act starts only from a prompt, a registered signal, or a
  countersigned release (Rule-3 Intake; dsys "three keys": the ambient can invent no work).
- **I7: every act carries its mode and a countersignature reference** (#153; `crafts/countersign`
  schema).
- **I8: silence is not consent.** An unanswered question authorizes nothing (Rule-3 "any other
  response"; dsys E5).

**Lifecycles, one per mode, built only from the primitives:**
- **explicit:** Prompt → Proposal (plan) → Countersignature → execute → Report + Proposal (done) →
  Countersignature.
- **implicit:** Signal → covered by a Mandate? If yes, execute within its scope, then Report. If no,
  Escalation → explicit.
- **automatic:** Release (countersigned) → the executor runs on a trigger → Events. An unhandled
  trigger becomes an Escalation → explicit.

**Preferences in the CIM** are standing countersignatures of two kinds:
- **form preferences** shape how Proposals and Reports look;
- **authority preferences** are Mandates.

dyad-system's eight, classified:

| preference | kind | note |
|---|---|---|
| `concise-mode` | form | one Report or Proposal per prompt |
| `batch-disposition-mode` | form | several questions folded into one |
| `merge-disposition` | form | the Done countersignature also covers merges |
| `delegation` | form | who drafts |
| **`ledger-pr-merge`** | **authority → Mandate** | already a standing countersignature; the #156 projector already emits it as `mandate-ledger-pr-merge` |
| `cli-pattern` | not interaction | command-line form |
| `import-licenses`, `import-support` | not interaction | import criteria |

### 2. Review: dsys slash commands (7) for inclusion
The principle, from #115's survivor: a slash command is an *adapter* that invokes a procedure,
never the procedure itself.

| dsys command | what it is | inclusion |
|---|---|---|
| `/pb-decide`, `/pb-extend` | run a decision or feature-expansion playbook; the Operator disposes | **Include as a pattern**, as `/pb-<playbook>` adapters for *countersign-system's own* play-books. dsys's playbook *texts* are not copied: dsys-repo has no LICENSE, so copying needs the Operator's licence decision |
| `/eval-meta`, `/eval-pb`, `/eval-rb`, `/eval-sc` | falsify a claim or evaluate an artifact against a definition | **Include as one command, `/falsify {claim\|path}`**, producing a Rule-9 record. The four are one procedure applied to four target kinds (Rule-9's Form), so one adapter with a target kind replaces them |
| `/sc-author` | author a command's design, contract and implementation | **Defer.** It is meta-authoring, needed once commands multiply |
