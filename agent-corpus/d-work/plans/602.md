## Definition of done (proposed by the engineer; amend with N and text)
Fixture rows #7, #8, #9, #10 exist; transcripts are synthetic (`dyad/tests/test_trace.py`).
- **Attribution by precedence.** Turns: A ends `Y/N: proceed with #7 …`; B is an operator message naming #8 whose
  reply has no `Y/N:`; C names neither; D's prose names #7, #8 and #9 and its `Y/N:` names only #8.
  `dyad dwork trace 7` counts A only; `trace 8` counts B and D; C is in no row's count; D is not in #7's or #9's.
- **PR numbers are not rows.** A turn ending `Y/N: Done with #7 w (merges PR #8, #9)?`, and one whose trigger says
  `PRs #8, #9 and #10` or `merged #9`, names neither #8 nor #9 nor #10. An id that is no row (`#9999`) names nothing.
- **Untrusted digits.** A notify text holding `#` followed by 5000 digits loads, and is ignored (no `ValueError`).
- **Triggers.** A fixture with an operator turn, a `notify` wake, a mid-turn queued notify, a `compact` resume and one
  reply before any trigger prints `| replies by trigger | operator N, notify N, compact N, none 1 | transcript |`
  with the fixture's numbers; the printed buckets sum to the row's replies (`none` printed only when non-zero). The
  mid-turn queued notify does not relabel its operator-opened turn.
- **Compaction keeps the ids.** Operator message naming #7, a compaction, then a reply with no `#7`: it counts in #7's
  replies, under `compact`.
- **Per-row denominator.** (a) A row whose provenance holds a `Y plan (mandate #570)` entry plus one real `Y`:
  denominator 1. (b) A row whose entries are all mandate-noted prints `no operator answer in the window (N replies)`.
  (c) A row holding one entry of a batch `Y` counts it once (regression guard; passes today). (d) A `relayed via
  <seat>` disposition that anchors in the transcript is counted.
- **Window-wide line.** One batch `Y` anchoring in #7 and #8 prints `| replies in the window, all rows | R replies,
  1 answers, overlap X.X | transcript |`, overlap = Σ per-row replies over the window's R (fails on today's code: no
  such line).
- **Two rules, stated.** A turn with no `Y/N:` attributed by its trigger is counted in Limits as one sentence naming
  `turns_naming_others`'s `Y/N:`-only reading and the number of turns the two read differently (asserted).
- One direct test per new function (`_ids`, `turns`, `replies_for`, `answers`, `window_answers`); the `SECRET`
  assertion (no transcript text in a trace) extends to every new fixture.
- `dyad check --tests dyad/tests/test_trace.py`, the whole `dyad/tests` root and `dyad check --guards` pass.
- Audit re-measures T2 once this lands (#591's follow-up, its own row, not this one).
