  craft not in the dict, taking the whole core suite down on a system that authors a new craft.

  (derived, as line 15 of the sysarch test already states the discipline); the literal list stays
  for the known ones. Test: a scratch install with an unlisted craft imports and passes.

  drops any path matching a `generated:` pattern (`dyadlib.package_rules`, the same data
  `package.py check` refuses tracked generated files by). Test: an untracked generated path under a
  kind's glob is not checked. syseng 0.1.2 → 0.1.3.

  `FIELDS`; the test now follows it); without sysadmin the change-log assertions are already gated.
  sysarch 0.1.3 → 0.1.4.
