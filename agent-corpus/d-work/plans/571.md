   read-only run-book command. Its event goes to `main` as an events-only commit.
2. **Group (Phase 1), full re-derivation, two views.** Two subagents each derive modes over all 252 rows, both
   forbidden the index, the mode records and the falsification directory, both reporting the sentinel first:
   - View 1 reads `cause` first and keeps small modes apart where their fences differ.
   - View 2 works bottom-up with the one-sentence test.

   This seat reconciles the two into the mode set and checks it mechanically: every row in exactly one mode, counts
   summing to 252. Each new mode is mapped to its 2026-10-10 / 10-24 / 10-26 predecessor(s), so a record's history
   is not lost.
3. **Plan (Phase 2).** For each mode, every live mitigation is read from the code and the Rule text at the
   execution base: path and identifier, the moment it fires, the rows reached and not reached, shipped or candidate,
   and recurrence after shipping. This includes the fences built since 2026-10-26 (#465, #474, #481, #495, #552's
   two, #560, #535/#536's board and inbox). Up to four subagents read in parallel, one per group of modes, and this
   seat verifies each claim it cites.
4. **Falsify "this mode is addressed."** One attack per mitigation and per gap, written in the index. Audit's
   charter keeps it out of `agent-corpus/falsification/`, so the amendment of
   `2026-10-10-incident-modes-addressed.md` is proposed to counsel, as on 2026-10-24.
5. **Close each mode (Phase 4)** as exactly one of:
   - (1) fenced, naming the fence and its moment;
   - (2) a `backlog` row naming the fence, either an existing row or a proposed new one;
   - (3) an impossibility on this kernel, naming the Rule that makes it so.
6. **Resolve the 21 `backlog` mode rows #262–#283.** Each is classed as one of:
   - **fenced**: retirement proposed, the ground being the fence that now closes it;
   - **owed**: stays `backlog`, re-pointed in the index to the fence it still names;
   - **superseded**: retirement proposed, the ground being the new mode that carries it and that mode's own row.

   Together these become one retirement-form question, `Y/N: archive #a, #b, …?`, for the cos to put to the
   Operator. New fence rows go in one separate proposal question.
