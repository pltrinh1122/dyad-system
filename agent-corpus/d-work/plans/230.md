## Falsification

  is its own Operator `Y` (Rule-11 Ratification events). Once the craft's new tag exists, the
  lagging row is no longer "older than an unreleased live version" and fails again. A bundle can't
  be tagged at a row the tree contradicts.
- **Attack: a warning is a weakened guard (#199 A4's objection to configuration).** It survives as
  scoped. The tolerance is mechanical and narrow: one direction (row behind), one state (live
  version untagged), the row naming a real release. It is the same shape as #156's unreleased-craft
  warning, which has held since 2026-09-24.

  fires spuriously.** Confirmed as a limit. Where no tags are present, `released_components`
  already treats crafts as unreleased (`check_drift` skips with a line). The new rule reads the same
  source, so it is no looser than the guard is today on such a checkout. The amendment states it.
