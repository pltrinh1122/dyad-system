the Operator wants the host triaged — which process is the frozen one, which must not be touched —
and then it killed. Identification is read-only and free (Rule-8 Classes). The kill is a host

action, even though this plan describes it (Rule-8 Classes, `crafts/sysadmin/rules/host-mutation.md`).
This plan is therefore stored so the act is bound to a written mutation, and the question asked is
Rule-8's, not Rule-3's plan form: the destructive counter-prompt is the one that must exist, and a
plan-`Y` cannot stand in for it.
