## Definition of done (*proposed*)
> One table I read: every number 1.0 lets me tune — its preference key, its allowed values, its default (stated in a
> DMC), and the line of code that reads it — with altitude among them; and, beside it, every number in the code that is
> *not* mine to tune, with the reason.

The report that answers it is the table, `agent-corpus/audits/2026-11-04-tunables.md`. The keys themselves reach
you as the home's preferences-zone question, asked with #590's Done (Rule-2: a preference value is never carried).

## Intent as read
#570 revision 6's test freezes the preference keys at 1.0 (H3), so every number you would tune after 1.0 must be a
key before the cut, or adding it later is a new surface. #570 attack A6 found the thresholds are constants in code,
outside your zone. #590 makes each one a preference whose meaning and default sit in a DMC (agent zone), read by the
code with that default, and gives you one table to read them by.
