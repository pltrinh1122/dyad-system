Two plan items cannot be achieved as written (incident, Rule-3):
- **The cut PR cannot pass its own evidence.** #505 (`bootstrap.clone_problems`, in this change set) refuses whenever
  `BUNDLE.md`'s core row names a version with no local tag, and the play-book's row PR always names the untagged
  version its own merge will cut (verified at `dyad/scripts/bootstrap.py:118`). So `check --evidence` exits 2 on the
  step-2 head (e6df436). That is a critical fix by the play-book's classes ("a release refused").

  bundle carry its 0.3.1 tree. With its row held at 0.3.0, v0.19.0 would publish a `cabinet-0.3.0.tar.gz` that differs
  from the published cabinet-v0.3.0 (b9bcadf3… against 76e3a792…). Attack 3 is **refuted** as stated. The same case
  released sysadmin 0.3.1 at #517.
