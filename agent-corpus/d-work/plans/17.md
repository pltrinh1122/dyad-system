# Plan #17 — batch-disposition-mode

Base commit of `main`: 3a29eff. Suspends the pending counter-prompt of #13/#16 (v0.3.2 permission),
which under this very mode is the first item of the next batch.

## Intent as read
The Operator wants to answer counter-prompts in batches: one `Y` that authorizes a *set* of plans,
and one `Y` that verifies a *set* of Dones (with their merges). The Agent detects the mode from the
Operator's conduct: a counter-prompt left unanswered — the next message is a prompt, not a `Y`/`N` —
means the Operator has engaged batch mode; the Agent stops asking per item, keeps every pending
counter-prompt in a queue, and asks the batch questions when the Operator asks for them or the
queue is presented at a natural point (end of a reply, session start).
