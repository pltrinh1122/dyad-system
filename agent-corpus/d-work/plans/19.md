## Intent as read
Abandon the PAT-based paths entirely (both the fine-grained `RELEASE_TOKEN` and the classic-PAT
test I'd just asked for). Reset the repo's Actions secrets to a clean slate, then publish releases
using a GitHub App's short-lived installation token instead of any personal-account credential.

unreferenced anywhere in the tracked tree, present before this session touched anything). Neither

Operator hit both live at `github.com/settings/apps/new` and caught it (falsification, below).
Full walkthrough of that form:
