names", written by `dwork state … --decisions` in the `Y done` commit. Nothing produces that file. Since #644 no
done-`Y` has written one, so #645, #646 and #647 added no candidate. The log holds #644's 29 entries and nothing

per record, too few to measure a bar.

| portion of the prompt | class | consequence |
|---|---|---|
| "candidate capture part of every Done" | new | each done-`Y` commit writes the row's rulings to `decisions/<row>.md` as `candidate` blocks, `source: done` |
| "generated by `dyad board draft`" | new, Rule-13 | `board draft <id>` gains a **Candidates** section and writes a `--decisions` file. It holds the row's **structured** rulings, read mechanically as `backfill.py` reads them: the plan file's verdict tables (`dmc:attack-result`), the row's release entries (`dmc:release-class`) and its change-log rows. It also holds a fixed slot for each **prose** ruling the completion evidence names, such as a departure ruled execution detail. The agent fills a prose slot, which is a judgement, and never a structured one |

A done-`Y` recorded with no file, while the draft listed candidates, is refused before any write, so capture cannot be skipped silently |
| (gate-first, #645) | overlap | capture writes candidates only. Admission stays the precedent question's, with `dyad precedent gate` run first |

## Definition of done (proposed, for the intent-Y to accept)
1. **Draft.** `dyad board draft <id>` prints a Candidates section and writes a `--decisions` file: the structured
   rulings read mechanically, plus a fixed slot for each prose ruling, filtered by A1. Tests cover each source and the
   filter.
2. **Record.** `board advance … answered-Y` and `dwork state … 'Y done …'` write the file in the Done record's commit.
   A done-`Y` with no file, where the draft listed candidates, is refused before any write. Tests cover both.
3. **Text.** Rule-3's Completion counter-prompt says the Record commit carries the candidates. The d-work play-book's
   Done step names the draft's section. Amendment #648 is in the Rule-3 record.
4. **Used once.** This row's own done-`Y` writes its candidates through the new path, or prints `Candidates: none`.
5. **One agent-zone PR**, with its evidence clean.
