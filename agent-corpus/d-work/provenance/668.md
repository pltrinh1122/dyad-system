```
> What I’d build: one decision record (a dmc) answering one question: “What does this pitch need before it is put to you?” The tests run in a fixed order, and the first one that fails decides the outcome:
> fenced: it names a private repository, a client, an employer, a person or personal context. Strike it first.
> no-reader: there is no named reader, or no single question it answers for them. Stop drafting.
> invented: it claims a capability the system’s purpose statement and practice don’t hold. Cut the claim.
> unanchored: a claim has no path, command output or count behind it, or wasn’t tested against what would make it false, or compares with a named product without showing it. Anchor it or cut it.
> decorated: superlatives, unexplained jargon, more than one idea per sentence, or content the reader can’t use. Rewrite.
> uncountered: the strongest objection a skeptical reader would raise isn’t stated with how the copy answers it. Add it.
> ready: every test holds. It goes to your publication question; ready never publishes anything.

you appear to be missing the emotional elements that connects and attracts the reader/recipient of marketing messages
```
